# -FLIPKART-WEBSITE-CLONE-

Flipkart UI Clone using HTML & CSS 

Developed a responsive Flipkart-inspired e-commerce website interface using pure HTML and CSS. The project replicates the core layout and design of the Flipkart homepage, including a sticky navigation header, search bar, category section, promotional banners, product showcase cards, and a multi-column footer. The design focuses on clean user experience, responsive layouts, modern styling, hover effects, and proper content organization.

## Key Features

Responsive Flipkart-style homepage design
Sticky header and category navigation bar
Search box with Font Awesome icons
Product showcase sections with promotional banners
Interactive hover effects on cards and banners
Fully structured footer with company information and social media links
Mobile-friendly layout using Flexbox, CSS Grid, and Media Queries
Clean and organized code structure

## Technologies Used

HTML5
CSS3
Flexbox
CSS Grid
Media Queries
Font Awesome Icons
